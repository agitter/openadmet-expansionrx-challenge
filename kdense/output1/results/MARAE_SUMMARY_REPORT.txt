MA-RAE METRIC DEFINITION
================================================================================

MA-RAE (Mean Absolute-Relative Error) is defined as:

    MA-RAE = MAE(model) / MAE(baseline)

where:
    MAE(model) = mean(|y_true - y_pred|)
    MAE(baseline) = mean(|y_true - mean(y_true)|)

Interpretation:
  • MA-RAE < 1.0: Model outperforms naive baseline (predicting mean)
  • MA-RAE = 1.0: Model equivalent to naive baseline
  • MA-RAE > 1.0: Model worse than naive baseline
  • Lower values are BETTER
