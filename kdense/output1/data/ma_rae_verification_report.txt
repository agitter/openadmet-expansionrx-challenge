TECHNICAL VALIDATION
================================================================================

MA-RAE Formula Verification:

Implemented Formula (both scripts):
    MA-RAE = MAE / MAE_baseline
    where:
        MAE = mean(|y_true - y_pred|)
        MAE_baseline = mean(|y_true - mean(y_true)|)

This formula is CORRECT. It measures the model's mean absolute error relative
to a naive baseline that always predicts the training set mean.

• MA-RAE < 1.0: Model outperforms naive baseline
• MA-RAE = 1.0: Model equivalent to naive baseline
• MA-RAE > 1.0: Model worse than naive baseline

All reported MA-RAE values are < 1.0, confirming both models are better than
the naive baseline for all properties.

Properties of MA-RAE:
✓ Scale-invariant (can compare across different target ranges)
✓ Interpretable (fraction of baseline error)
✓ Handles different magnitudes across properties
✓ Lower values are better
✓ Well-suited for multi-task evaluation

Cross-Validation Methodology:
✓ Scaffold-based 5-fold CV (prevents data leakage)
✓ MA-RAE calculated per fold, then averaged
✓ Both mean and standard deviation reported
✓ Overall MA-RAE also calculated from all out-of-fold predictions
✓ Consistent methodology between baseline and GNN models
